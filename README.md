## The word

> Clingy

(6 characters, one word.)

The word every ex has said at least once, usually while backing toward the door. It stings because it is true, and I know it — which is exactly why it is funny.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the word to `/output/entry.txt`, then prints it.

## Run it

```sh
python3 main.py
```
